# Algorithm Solver

Algorithm Solver is a full-stack optimization platform that uses mathematical programming (SCIP) to solve inventory optimization problems. It maximizes profit by determining optimal product ordering quantities while respecting constraints like budget, warehouse capacity, shipping weight/volume limits, and demand forecasts.

The system features a Python backend with FastAPI and gRPC services, a React frontend for configuration and visualization, and runs in Docker containers with PostgreSQL for data persistence.

The frontend is currently in development stage - expect bugs and missing features.
